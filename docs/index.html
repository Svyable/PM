MULTIPLY THE STARTING POINTS

Your project already contains the work. Give it a signal.

PM is built for people who run ambitious projects through ChatGPT: authors, researchers, builders and anyone managing a collection of related threads.

↗

Open the actual chats

Uses the conversation links already inside your project, opening each selected thread in a browser tab.

⇣

Scroll beyond the fold

Discovers older conversations as the project list lazy-loads, without stopping at the first visible screen.

⌘

Prompt once, send many

Use “proceed methodically” or your own instruction. PM enters the text and submits it, one chat at a time.

◇

Choose the effort

High by default. Select another supported effort level, or keep each conversation's current setting.

Ⅱ

Pause, stop, inspect

Watch progress, see skips and failures, preserve existing drafts, and avoid blind retries of uncertain submissions.

◈

Local by design

No PM account, backend, analytics or private ChatGPT API. Just a browser extension you can audit.

Starting a run

  1. Sign in to ChatGPT and open your Project overview URL ending in /project.
  2. Click PM. It should recognize the project page; if not, use Reconnect and verify extension site access.
  3. Set a conversation count, edit the prompt if desired, select effort and spacing, then click Launch PM.
  4. PM scans the project list, opens matching chats one by one, fills the prompt, selects effort, sends, and records results.
  5. Keep Chrome open while it runs. Reopen the popup to inspect status and recent activity.

Understanding results

Sent means PM observed a newly rendered user message matching the command, not merely an empty composer. Skipped includes deliberate protections such as an existing unsent draft. Unconfirmed means a send may have occurred, but its acceptance was not verified; inspect the chat before attempting it again. A run can pause when confirmation is ambiguous or repeated errors occur.

Each result includes an Open ↗ link so you can inspect that chat. Pause stops the launch of new chats after the current operation. Stop prevents remaining launches. Neither action can undo a message that has already been sent.

Troubleshooting

SymptomWhat to try
Project not detectedUse the Project overview, not an individual conversation URL.
“Receiving end does not exist”Click Reconnect, check PM site access to chatgpt.com, or reload the project tab and extension.
Cannot confirm effortTry a one-chat pilot with “Keep current.” ChatGPT may have changed its effort menu.
Send not confirmedInspect the target chat before manually resending. Avoid duplicates.
Only some chats discoveredWait for the scan and avoid navigating the project tab; UI lazy-loading may have changed.
Run pausesReview the latest error and the affected chat before resuming.

What PM is — and isn't

PM is a local, user-triggered UI automation tool for existing ChatGPT Project conversations. It does not create a coordination layer where conversations read or share each other's answers. It does not grant more context, subscriptions, parallel-compute quota or exemption from ChatGPT usage limits. A project may provide shared instructions and project files, but each conversation still operates independently.

PM does not call undocumented ChatGPT endpoints, collect generated responses, run a server, or transmit analytics. The current beta has simulated DOM tests; full authenticated, live-site operation has not been independently verified. The source is public for inspection and contributions.

GOOD QUESTIONS

Frequently asked.

Is PM free?

Yes. The source is visible in the public Svyable/PM repository. You still need whatever ChatGPT access your own plan provides.

Can it really launch 100 chats?

It can queue up to 1,000 existing project conversations, but successful sends depend on the site's UI, browser resources and your plan limits. Start small. 100 simultaneous completions are not guaranteed.

Is this an official OpenAI product?

No. PM is an independent extension, unaffiliated with OpenAI. ChatGPT is a trademark of its owner.

Do the chats collaborate with one another?

No. PM dispatches a shared instruction to separate conversations. Coordination, result synthesis and shared state across chats would require additional architecture.

What happens to existing drafts?

PM is designed to skip chats with unsent composer text rather than overwrite your work.

What if ChatGPT changes its layout?

Selectors can break. PM reports uncertain sends rather than pretending success, and the source-available code can be updated to fit new UI patterns.
