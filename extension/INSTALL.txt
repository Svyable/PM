PM 0.9.1 — Proceed Methodically (v1 feature candidate)

Install:
1. Extract the ZIP.
2. Open chrome://extensions and enable Developer mode.
3. Choose Load unpacked, then select the extracted extension/ folder.
4. Reload an already-open ChatGPT Project overview page.

Choose what PM does:
- Continue existing: send your instruction to existing threads in the Project.
- Start new: submit your instruction as the FIRST message in brand-new conversations inside the Project.
- Mixed: select how many NEW threads to create; the rest continue existing chats.
  PM continues existing chats first and then creates new threads.

Start with a test run of ONE conversation (High effort or Keep current).
Review the actual message and project membership before scaling.
New chats are created by sending a message; PM does not create blank threads.
Unconfirmed sends are NEVER retried automatically.

Independent candidate, not affiliated with OpenAI. Usage limits and service rules apply.
Source and support: https://github.com/Svyable/PM

Effort-picker fix: PM now detects an already-selected High effort and waits for slow picker menus. If effort remains unverified, it will not Send. You can choose Keep current to test the rest of the workflow, but that does not set High for you.
