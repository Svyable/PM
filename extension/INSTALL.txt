Install:
1. Extract this ZIP.
2. Open chrome://extensions and enable Developer mode.
3. Click Load unpacked and choose the extracted extension/ folder.
4. Reload any already-open ChatGPT Project overview tab.
5. Confirm the right-side PM command center appears; test one chat.

Only send after checking that your requested effort is available.
Do not run a large batch until a real one-chat send has been verified.
